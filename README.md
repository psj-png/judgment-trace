# judgment-trace

Claude Code·Codex 작업 기록에서 내가 내린 판단을 근거와 함께 뽑아내는 도구.

## 왜 만들었나

AI 에이전트와 함께 작업하면 코드는 남지만, 그 과정에서 내가 무엇을
거부하고 무엇을 요구했는지는 대화 기록 속에 묻힌다. 이 도구는 그 대화
기록에서 사람의 판단을 찾아 결과(테스트·커밋)와 연결해 기록으로 남긴다.

## 기존 도구와의 차이

| 도구 | 기록하는 것 | 용도 |
|---|---|---|
| GitHub | 커밋·diff·PR (결과) | 버전 관리·협업 |
| agent-retro, retro | 사용자 정정 | 에이전트 규칙 개선 |
| devlog, 세션→블로그 생성기 | 에이전트 시점의 작업 서술 | 개발 일지·블로그 |
| judgment-trace | 사람의 판단 + 근거 | 판단 증명 (면접·포트폴리오) |
